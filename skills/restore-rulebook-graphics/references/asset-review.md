# 이미지 자산 검수 기록

자산마다 아래 정보를 실제 프로젝트의 자산 목록이나 이슈 기록에 남긴다. 단일 이미지 수정에는 한 행 또는 짧은 기록이면 충분하다.

| 항목 | 기록할 내용 |
| --- | --- |
| 원본 | 파일 경로·해시, 판본, PDF 페이지/인쇄 쪽, 원본 영역 또는 PDF 객체 ID |
| 적용 크기 | 결과물이 페이지에서 차지할 가로·세로 길이, 원본과 결과의 픽셀 크기, 각 방향의 유효 ppi 또는 벡터 여부 |
| 의미 기준 | 원본/에라타에서 확인한 문구·숫자, 아이콘의 형태·개수·색, 경로·방향·상대 위치 |
| 처리 | 원본 보존, 같은 판본 자산 재사용, 결정적 확대·보정, AI 복원·재생성 중 실제 사용한 방법과 도구 |
| 결과 | 후보 파일 경로·해시, 원본/결과 비교본, 확대 크롭, 수정 영역 |
| 판단 | 정보 일치 여부, 남은 불확실성, 검수 상태, 영향을 받는 페이지 PDF·합본 |

## 비교할 때

- 원본과 후보의 **물리 크기와 크롭 영역**을 맞춘다. 확대 미리보기만으로 인쇄 결과를 판단하지 않는다.
- 글자, 숫자, 화살표, 연결선과 반복 아이콘은 개수뿐 아니라 모양·색·순서를 대조한다. 에라타가 원본 그림을 고친다면 수정 전 원본과 에라타의 차이를 별도 표시한다.
- 다른 판본의 그림을 후보로 썼다면 누락·추가된 개체가 없는지 전 영역을 검사한다. 해상도만 좋아졌다는 이유로 승인하지 않는다.
- 국소 수정을 했으면 수정 영역 바깥이 그대로인지 영상 차이로 확인한다. 색 관리·렌더러 차이로 픽셀 전체가 달라지는 경우에는 그 한계를 적고 구조적 차이를 별도로 확인한다.
- 생성된 부분에는 원본에 없는 장식적 세부가 생길 수 있으므로 정보성 도형은 원본 객체/정확한 도형과 겹쳐 비교한다. 검수되지 않은 생성 후보는 완성 자산으로 분류하지 않는다.
