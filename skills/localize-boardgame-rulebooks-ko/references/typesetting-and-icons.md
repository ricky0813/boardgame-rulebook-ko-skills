# PDF 조판·아이콘 작업

## 배경과 보존 요소

- PDF를 이미지 배경, 텍스트 객체, 벡터 아이콘·장식으로 분해할 수 있는지 먼저 확인한다. 원래 무문자 배경 층을 얻을 수 있으면 그 층을 사용해 자연스러운 질감을 보존한다. 평탄화된 이미지 속 글자와 PDF 추출에서 빠진 윤곽선 글자는 별도 영역으로 표시해 복원한다.
- 제거 대상을 `번역할 영문`과 `남길 시각 요소`로 분류한다. 로고, 페이지 번호·배지, 카드 번호, 원문과 무관한 A/B 단계 기호, 화살표, 가문 문장과 언어 중립 아이콘은 보존 후보이다. 원래 기호가 살아 있으면 다시 그리지 않는다.
- 그림 속 영문 목록을 페이지·영역·처리 상태로 관리한다. 무문자 배경을 얻었어도 카드 사진·도해의 래스터 영문은 남을 수 있다. 큰 표지 부제, 세로 헤더, 작은 예시 카드 효과문을 최종 렌더에서 확대 확인한다.
- 질감 복원이나 마스크는 패널의 둥근 모서리, 색상 바, 규칙선·그림자와 하단 경계 안에서 끝나야 한다. 불투명 사각형이 경계 밖으로 튀거나 텍스트를 덜 가리면 패널 전체의 배경 또는 인접 질감에서 다시 복원한다. 경계선을 가렸다면 경계선까지 복원한다.

## 텍스트 영역과 서체

- 실제 PDF의 포인트 크기와 논리 페이지를 먼저 정한다. 렌더링 검사 격자와 PDF 좌표를 혼동하지 않는다. 펼침면을 나눌 때 중앙 절단선과 쪽 번호 위치를 확인한다.
- 카드·타일마다 제목 바, 능력별 위/아래 칸, 좌우 결과, 선택지 목록을 별도 프레임으로 지정한다. 원문의 가로선이 독립 능력을 나누는지 한 능력 안의 선택지를 나누는지 구별한다. 가운데 띠와 다음 카드의 테두리를 침범하지 않는다.
- 기존 한국어판의 실제 글꼴 파일을 알 수 없으면 확대 글리프·자폭·행간을 설치 글꼴과 비교해 근사한다. 원문 영문 크기를 그대로 복사하지 말고 한국어판의 위계와 인쇄 크기를 함께 본다. 특정 프로젝트의 닉스곤체·21.5pt 같은 수치는 재사용 사례이지 보편 규격이 아니다.
- 전체 본문을 일괄 축소해 카드 안에 큰 빈 공간이 남게 하지 않는다. 문장 다듬기, 프레임 폭, 문단 간격, 줄바꿈을 먼저 조정하고 긴 칸만 개별 축소한다. 어절 중간 분리와 마지막 한두 음절의 외톨이 행을 피한다.
- 제목은 아이콘 오른쪽 여백과 색상 바의 수평·수직 중심을 기준으로 맞춘다. `간부 카드`처럼 첫 글자가 아이콘 밑에 들어가거나 여러 카드 제목이 미묘하게 위로 뜨는지 전체 페이지에서 함께 검사한다. 색상·굵기·크기는 원본의 제목 위계와 비교한다. 어두운 배경에는 밝은 원문 텍스트의 대비를 유지한다.
- 표지는 두 개의 독립된 제목이 아니라 한 묶음으로 보이는지 좌우 외곽과 중심을 본다. 굵은 서체가 과하면 같은 글꼴의 중간 굵기에 미세한 같은 색 외곽선을 더하는 방법을 시험할 수 있다. 시리즈 책자의 표지 문구는 실제 글꼴·포인트·획 설정을 대조해 통일한다.
- 사용자가 표지 게임 타이틀을 한국어 이미지로 선택한 경우 [표지 타이틀 스킬](../../localize-rulebook-cover-title-ko/SKILL.md)의 타이틀 자산을 사용한다. 원본 분위기와 정확한 한국어 표기, 주변 부제·날짜·그림과의 관계를 표지 적용 미리보기에서 확인한다. `영문 유지` 선택을 다른 표지 문구의 번역 금지로 확대 해석하지 않는다.

## 아이콘과 도해

- 아이콘 목록에는 의미, 고유 ID, 원본 페이지·추출 경계, 파일 경로와 해시를 기록한다. 연락판으로 의미와 이미지가 일치하는지 확인한다. **원본 좌표는 추출 증거이지 한국어 삽입 좌표가 아니다.**
- 원본 도해가 흐리면 내장 객체의 벡터 여부·픽셀 크기와 실제 조판 크기에서의 유효 해상도를 확인한다. 높은 dpi로 페이지를 렌더링한 것만으로 내장 그림의 세부가 복구되지는 않는다. 개선이 필요하면 [이미지 복원 스킬](../../restore-rulebook-graphics/SKILL.md)을 적용해 같은 판본의 정확한 자산, 원본 도형 재사용, 확대·보정, 필요한 영역의 재생성 순으로 검토하고 각 후보의 의미 일치와 출처를 남긴다.
- 생성 이미지 안의 규칙 정보성 아이콘·숫자·방향은 원본과 에라타를 기준으로 따로 대조한다. 원본의 정확한 작은 도형을 재사용할 수 있으면 새 그림 전체를 다시 생성하지 않는다.
- 번역 문장을 먼저 줄바꿈한 뒤 관련 용어 옆에 아이콘을 놓는다. 용어와 아이콘, 조사·콜론을 한 단위로 보고 줄을 넘긴다. 글자 기준선, 높이와 앞뒤 간격을 맞춘다. `채굴 [아이콘]:`의 아이콘 뒤 콜론까지 확인한다.
- 아이콘이 배경에 남아 있으면 그대로 사용한다. 이동이 필요한 경우에는 원래 아이콘 자국을 자연스럽게 지우고 새 위치에 **한 번만** 넣는다. 원래 그림 안의 관계를 보존해야 하는 도해 아이콘과 문장 흐름에 맞춰 움직이는 인라인 아이콘을 구별한다.
- 글자만 이동시켜 깃발과 설명이 멀어지거나 왼쪽 정렬이 깨지지 않게 한다. 아이콘·텍스트·콜론·선택지의 묶음 전체를 함께 조정한다. A/B 표식이 독립 그래픽이면 원본을 남기고 그 옆 문구의 기준선만 맞춘다.

## 실제 렌더에서 반복해 찾을 결함

1. 검정 글자가 어두운 배경에 올라간 곳, 원본보다 지나치게 작거나 가벼운 제목·본문.
2. 카드 열을 가로지른 문장, 제목의 높이와 중심 불일치, 아이콘이 첫 글자를 가린 곳.
3. 영문 덮개 패치의 돌출·잔여 글자·테두리 또는 하단선 손실.
4. 두 겹 아이콘, 아이콘과 명사의 먼 간격, 누락된 콜론·호출 기호.
5. 그림 속 남은 영문, 잘린 글자, 쪽 번호·A/B·숫자 배지의 중복 또는 소실.
