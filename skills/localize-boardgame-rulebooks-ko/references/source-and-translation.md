# 원문·번역 대조

## 원본 판별

- 제공 파일마다 파일명, 출처, 크기, 해시, PDF 물리 페이지 수, 인쇄 쪽수, 페이지 크기, 텍스트/이미지 구조를 기록한다. 표지가 단면이고 중간이 펼침면이면 `물리 페이지 → 인쇄 왼쪽/오른쪽` 대응표를 만든다. 사용자와 한 쪽씩 진행할 때의 쪽수는 보통 **인쇄 논리 쪽수**다. PDF 뷰어의 물리 페이지 인덱스와 혼동하지 말고 해당 쪽이 펼침면의 어느 편인지 확인한다. A4로 만든 이전 책자 때문에 새 A5 책자까지 A4로 내보내지 않는다.
- 사용자가 준 `final`을 파일명만 보고 초안으로 취급하지 않는다. 다른 websafe·후속판은 별도 증거다. 문구 차이는 카드 번호와 원문을 나란히 적고, 선택한 번역 기준과 이유를 기록한다. 한 판본의 그림에 다른 판본의 더 긴 문구를 얹는다면 칸 높이도 다시 검수한다.
- 제공된 에라타와 확인 가능한 공식 정오표는 대상 판본·버전·날짜를 대조해 적용 여부를 정한다. 채택 항목은 `위치 / 인쇄 원문 / 정정 내용 / 번역·그림 반영 위치`로 추적한다. 서로 모순되거나 적용 판본이 불명확하면 임의로 합치지 말고 이슈로 남긴다. 나중에 에라타가 들어오면 원문 자체의 오류와 기존 번역의 오류를 구별해 영향을 받는 원고·이미지·페이지·합본을 갱신한다.
- 추출 텍스트의 빈칸은 원본의 빈칸이라는 뜻이 아니다. 페이지를 렌더링하고, OCR로 누락 후보를 찾되 OCR의 카드명·숫자는 이미지를 확대해 확인한다. 두 열 추출이 뒤섞이면 읽기 순서는 페이지 이미지와 카드 경계로 재구성한다.
- 출처가 확인되지 않은 솔로·2인 예외 수치를 다른 인원 수에서 유추해 넣지 않는다. 원문의 공백은 이슈로 남기고 확정된 내용만 번역한다.

## 기존 한국어판과의 접합

1. 영어 기본판과 한국어 기본판의 해당 규칙·구성물·카드명을 쪽별로 대조한다. 이미지 전용 한국어 PDF는 OCR 결과를 원본 이미지로 재확인한다.
2. 용어집에 영어 원어, 채택 한국어, 상태(기존 확정·통일 표기·신규 잠정·편집 제안), 근거 쪽, 별칭·금지할 혼용을 남긴다. 예를 들어 기본판의 `Bonus action = 추가 행동`을 받아들였다면 본문·카드·아이콘 참조에서 `보너스 행동`이 새 개념처럼 나타나지 않게 한다.
3. 같은 영어가 문맥별로 다른 대상을 가리키는지 검사한다. 자동 상대 집단과 구성원 한 명, 메인 보드의 구역과 개인 보드의 구역, 자원 이름과 신규 함선 이름은 단복수·대상을 구분해야 한다.
4. 기본 게임에 없던 확장 예외는 기존 설명을 덮어쓰지 않고 적용 범위를 명시한다. 모듈이 둘 이상이면 모듈별, 기본/2인/솔로별 적용표가 유용하다.

## 번역 원고와 의미 검수

- 조판 전에 인쇄 쪽 단위의 영한 대조 원고를 만든다. 카드·타일에는 `종류 + 번호 + 원제 + 한국어 제목 + 능력 칸/좌우 결과` 색인을 두어 누락·중복을 검사한다. 본문과 도해에 반복된 카드 문구도 서로 대응시킨다.
- `may/must/must if able`, `and/or`, `up to`, `at least`, `once`, 비용과 보상, 시점(`직후`/`단계 끝`), 조건의 범위, 우선순위와 동률 해소를 별도로 확인한다. 예: 두 문장에 각각 `may`가 있으면 두 효과가 독립적으로 선택 가능한지 한국어에서도 드러나야 한다.
- 복수 함선·복수 구역에 합계를 나눌 수 있는 효과, 카드별 점수에 다른 수량을 곱하는 효과, `왼쪽/오른쪽` 반전, 참조 번호는 그림과 함께 검사한다. 숫자·카드 번호의 기계적 일치만으로 의미 검수가 끝나지 않는다.
- 기존 한국어판의 문체를 참고하되 규칙문과 서사 인용문의 목소리를 구별한다. 원문에 없는 동점 설명·교정 안내를 자연스러운 규칙 문장 속에 조용히 추가하지 않는다. 원문 오기 수정이 필요하면 채택 본문과 원래 표기를 이슈 기록에 분리한다.
- 고유명사와 제작진 이름은 원문 철자·악센트를 그대로 대조한다. 글꼴 미지원 글자를 대체 문자로 방치하지 말고 해당 줄에 쓸 수 있는 글꼴을 찾는다.

완료 판정은 페이지 번호가 연속이고, 카드·타일·아이콘 참조의 항목 수와 각 능력 칸이 원본 이미지 기준으로 빠짐없이 대응할 때 내린다. 번역 검수와 디자인 검수의 범위를 구별해 기록한다.
