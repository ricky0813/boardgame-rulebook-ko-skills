# 페이지별 검수·합본·납품

계획·용어·전체 번역·자산 준비도 `SKILL.md`의 단계별 승인 절차를 따른다. 다음 절차는 조판 PDF와 비교 자료를 준비한 후 페이지별 승인을 받기 위한 것이다.

## 페이지별 반복

1. 해당 인쇄 쪽의 원문 이미지, 번역문, 카드/타일 색인, 아이콘·내장 영문 목록을 함께 연다.
2. 배경에 남길 그래픽을 확인하고 한국어 텍스트를 독립 프레임에 조판한다. 카드 표제는 실제 배지의 중심, 본문은 자신의 열과 구분선 안쪽을 사용한다.
3. 페이지 PDF를 만들고 원문과 같은 물리 인쇄 크기로 나란히 렌더링한다. 전체 균형 뒤에 150–300dpi 확대본으로 작은 카드 문구, 덮개 경계, 아이콘과 하단선을 본다.
4. 번역은 해당 원문과 다시 대조한다. 제목과 번호뿐 아니라 선택 가능성, 비용, 수치, 시점, 좌우 분기, 페이지·카드 참조를 확인한다.
5. 원문의 **실제 굵게/기울임 처리된 구간**과 한국어판의 대응 구간을 맞춘다. 원본에 PDF 글꼴 정보가 있으면 텍스트 span과 렌더를 함께 보고, 윤곽선·래스터 글자라면 확대 렌더로 확인한다. 번역 과정에서 임의로 다른 단어를 강조하지 않는다.
6. 발견한 문제를 페이지 로그에 `번역/배치/타이포/아이콘/배경`으로 분류해 수정한다. 수정 뒤 나란히 비교한 PNG를 다시 생성하고 사용자에게 인라인으로 보여준다. 페이지 PDF와 함께 `사용자 검토 중`으로 기록하며 새 수정본을 승인으로 간주하지 않는다. 사용자가 번역만 검수하라고 하면 디자인 평가는 그 검수에 섞지 않는다.

전문 리뷰를 따로 요청받은 경우, 원본·현재 PDF·용어 기준을 같은 페이지 단위로 보여주고 확정 결함과 권고를 구분한다. 서브에이전트 사용은 요청이나 현재 환경의 지침에 맞춘다. 리뷰 결과를 적용했는지는 원인, 수정 파일, 새 렌더와 재검수 상태로 추적한다.

## 최종 PDF

- 승인된 논리 페이지를 원래 인쇄 순서로 합친다. 표지는 단면, 가운데 펼침면은 분할된 각 쪽, 뒤표지는 원본 유지일 수 있다. 마지막 페이지에 번역 문구가 없다고 빈 페이지로 만들지 않는다.
- 필요한 경우 고화질 편집·보관용 마스터와 이미지만 압축한 배포용을 만든다. 벡터 텍스트·아이콘은 유지하고, 배경 이미지만 조절하는지 확인한다. 파일명과 크기 차이를 사용자에게 명확히 설명한다.
- 개별 페이지를 나중에 고쳤다면 **마스터와 압축본을 둘 다 재생성**하고, 배포용 복사본도 동일한 최신 파일인지 해시로 확인한다. 예전 합본 하나만 남기지 않는다.
- 에라타·번역·이미지 자산을 나중에 고쳤다면 영향을 받는 원고, 자산 목록, 페이지 PDF와 비교본, 합본을 순서대로 갱신한다. `원본/에라타 → 원고·자산 → 페이지 → 합본`의 연결을 경로·해시로 확인하고, 이전 파일의 승인 상태를 새 파일에 기계적으로 복사하지 않는다. 사용자에게 변경된 부분과 새 검토 자료를 보여준다.
- 합본 직전 기준 판본과 채택한 에라타 목록을 다시 대조해 반영 누락이 없는지 확인한다. 최종 렌더의 도해도 에라타 반영 전 그림과 혼동하지 않는다.
- 완성된 파일을 다시 열어 전 페이지의 크기, 쪽수, 순서, 핵심 문구의 한국어 텍스트 추출, 글꼴 임베딩, `{{icon:...}}` 같은 자리표시자·깨진 문자·잔여 영문을 검사한다. 번역문이 없는 표지·뒤표지는 기대 상태를 따로 설정한다.
- 전체 연락판에서 흐름을 보고, 한 쪽 확대본에서 겹침·잘림·패치와 아이콘을 확인한다. 압축본의 몇 쪽을 마스터와 렌더링 비교해 이미지 품질과 문자 선명도를 검증한다. 자동 검사가 통과해도 시각 검수는 생략하지 않는다.
- 최종 PDF와 검수 기록을 제시한 뒤 사용자 승인을 받는다. 승인 전 상태는 `최종 검토 중`이며, 파일 생성·기술 검수 통과를 사용자 승인과 동일시하지 않는다.

## 검수의 해석

- 번역 원고 완성과 최종 조판 완성은 다른 상태다. `번역 완료`, `조판됨`, `사용자 검토`, `승인`, `합본 반영`을 혼동하지 않는다.
- 디자인·번역을 한꺼번에 확인할지, 번역 내용만 확인할지는 사용자의 현재 요청을 따른다. 사용자가 특정 색·무게·위치를 지적하면 그 사례를 다시 렌더링해 확인하고, 다음 쪽에도 같은 결함 유형이 있는지만 살핀다.
- 본문에 적어 넣지 않은 원문 오류와 판본 차이, 잠정 용어, 미해결 적용 범위는 별도 이슈 기록으로 전달한다. 불확실함을 확정된 번역처럼 숨기지 않는다.
